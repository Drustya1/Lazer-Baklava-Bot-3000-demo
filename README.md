# Lazer-Baklava-Bot-3000
A chaotic, fun and slightly overpowered AI-powered “Lazer Baklava” bot. Includes commands, mini-games and humor modules.

## Text Adventure

`game.py` içerdiği küçük metin tabanlı macera sayesinde Lazer Baklava Bot 3000'i sokaklardan uzay pistine kaçırabilirsin. Oyun, tamamen terminal üzerinde çalışır.

### Nasıl çalıştırılır?

```bash
python game.py
```

### Oynanış

- WASD veya `up`, `down`, `left`, `right` yazarak hareket et.
- `eat` komutuyla çantadaki soğuk baklavayı ye ve +1 can kazan.
- `baklava` komutuyla Nintendo Switch 2 dâhil envanteri görüntüle.
- İnsanlara veya köpeklere yakalanırsan can kaybedersin. Enerjin biterse mahalle baştan yüklenir.
- Uzay pistine ulaşıp Mahmut Bey'e 1.000.000 TL'yi vererek Mars'taki Robot Diyarına geçiş yap.
